I. GIỚI THIỆU CHUNG
- Tên dự án: Sudoku Web App
- Tác giả: Jhanh (Nguyễn Quốc Khánh)
- Bản quyền: Giấy phép MIT (Open Source)
- Nền tảng: Web thuần túy (Vanilla HTML5, CSS3, JavaScript ES6+)
- Triết lý phát triển cốt lõi:
  1. ZERO DEPENDENCIES: Tuyệt đối không phụ thuộc vào bất kỳ thư viện hoặc framework
     nào (không dùng React, Vue, jQuery, Tailwind, Bootstrap, npm, node_modules...).
  2. PLUG & PLAY (CHẠY NGAY KHÔNG CẦN CÀI ĐẶT): Người dùng chỉ cần nhấp đúp file
     index.html hoặc chạy ChoiGame.bat (trong file zip) là chơi được ngay lập tức.
  3. RESPONSIVE FIRST: Tối ưu hoàn hảo cho cả thiết bị di động (Mobile dọc), máy
     tính bảng (Tablet) và máy tính để bàn (Desktop).
  4. NATIVE STORAGE: Lưu trữ toàn bộ trạng thái ván cờ, thống kê thành tích và hồ
     sơ cá nhân trực tiếp trên LocalStorage của trình duyệt với cơ chế dự phòng
     in-memory store.
  5. QUY CHUẨN PHIÊN BẢN: Đặt tên theo chuẩn 2 số tinh gọn (v1.0, v1.1, v2.0...)
     thay vì 3 số (v1.0.0) để đảm bảo ngắn gọn, trực quan.

III. CÁC PHƯƠNG THỨC KHỞI CHẠY TRÒ CHƠI
--------------------------------------------------------------------------------

1. CHƠI TRỰC TIẾP TRÊN TRÌNH DUYỆT (ONLINE):
   - Truy cập trang GitHub Pages: https://jhanh.github.io/Sudoku_game/
   - Hoạt động ngay lập tức, tự động lưu dữ liệu vào LocalStorage của thiết bị.

2. CHƠI OFFLINE QUA BẢN PHÁT HÀNH (OFFLINE 1-CLICK LAUNCHER):
   - Tải file Sudoku-Game-v1.0.zip hoặc Sudoku-Game-testing.zip.
   - Giải nén thư mục ra máy tính.
   - Nhấp đúp chuột vào file "ChoiGame.bat" bên trong để tự động mở trình duyệt.
   - Lưu ý quan trọng: File ChoiGame.bat chỉ tồn tại bên trong file zip, TUYỆT ĐỐI
     không để file .bat thừa ra ngoài thư mục gốc của repository.

3. KHỞI CHẠY BẰNG MÁY CHỦ PYTHON NỘI BỘ (LOCAL DEV SERVER):
   - Chạy lệnh: python server.py
   - Máy chủ SimpleHTTP sẽ tự động khởi động tại cổng 3000 (hoặc tự động đổi cổng nếu
     bị trùng), kích hoạt cờ No-Cache và tự động bật trình duyệt web tới localhost.
   - Nhấn phím Ctrl + C trong cửa sổ terminal để tắt máy chủ.

4. NHẤP ĐÚP TRỰC TIẾP FILE index.html:
   - Vì ứng dụng không có file ngoài bị chặn bởi CORS policy, việc nhấp đúp file
     index.html trên Windows/macOS/Linux sẽ mở game hoàn toàn bình thường.
